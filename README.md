# PaddyWise

React implementation of the PaddyWise SLIIT research project site.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```sh
npm install
npm run dev
```

Create a `.env` file from `.env.example` and set `VITE_TEAM_EMAIL` to show the team contact address and enable the copy button.

Put research PDFs in `public/files/` and team photos in `public/team/`. Their expected filenames are retained from the original page.

## Production build

```sh
npm run build
npm run preview
```
